# TRESOMAT Docs V2.3 – Changelog

- Das V2.2-Design und das korrigierte TRESOMAT-Logo bleiben unverändert.
- Die bisherige Public/Protected-Struktur wurde in Public, Techdocs und API aufgeteilt.
- Jeder Build besitzt Startseite, Navigation, Suchindex und Ausgabeverzeichnis getrennt.
- Rollenfremde Seiten werden per Allowlist vor der Verarbeitung aus dem Build entfernt.
- Rollenfremde Querverweise werden in der Ausgabe zu neutralem Text ohne Link.
- Public wird weiterhin auf GitHub Pages veröffentlicht; Techdocs und API entstehen als getrennte Artefakte.
